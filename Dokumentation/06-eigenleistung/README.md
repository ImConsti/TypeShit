# 6. Eigenleistung

Jede Person im Team muss eine Funktion Ende-zu-Ende (gesamter Frontend- und
Backend-Code für diese Funktion) umgesetzt und dokumentiert haben. Jede Person bekommt dafür eine eigene
Datei in diesem Ordner, benannt nach der Matrikelnummer.

## Pflichtinhalt pro Datei

1. Beschreibung der Funktion
2. Einbindung in das Gesamtprojekt
3. Angabe des entwickelten Codes (Dateien/Commits)
4. Zugrundeliegende Ideen und Funktionsweise
5. Entscheidungen, die bei der Entwicklung getroffen wurden (inkl. Begründung)
