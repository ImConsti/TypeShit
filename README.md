## Project Structure

```
TypeShit/
├── frontend/   # Next.js 16 + React 19 app (TypeScript)
└── backend/    # Express 5 API server (TypeScript)
```

## Frontend

Built with [Next.js](https://nextjs.org/) and React 19.

```bash
cd frontend
npm install
npm run dev     # starts dev server on http://localhost:3000
npm run build   # production build
npm start       # run production build
```

## Backend

Built with [Express 5](https://expressjs.com/) and TypeScript.

```bash
cd backend
npm install
npm run dev     # starts dev server via ts-node on http://localhost:3001
npm run build   # compile TypeScript to dist/
npm start       # run compiled output
```

### Endpoints

| Method | Path      | Description  |
|--------|-----------|--------------|
| GET    | `/health` | Health check |

## Running the full project

Open two terminals and start each service:

```bash
# Terminal 1 — frontend
cd frontend && npm run dev

# Terminal 2 — backend
cd backend && npm run dev
```
